# MERN Recipe App

A full-stack **MERN Cook_Ease Application** where users can explore recipes and authenticated users can **add, save, and manage their own recipes** using a custom-built REST API.

---

## Features

### 👤 Authentication
- User Registration & Login (JWT-based authentication)
- Secure password hashing
- Protected routes for logged-in users

### Recipes
- View recipes without login
- Add new recipes (only logged-in users)
- Save favorite recipes
- User-specific recipe management

### User Dashboard
- View user profile
- Manage added and saved recipes

---
